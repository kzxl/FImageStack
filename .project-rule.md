# FImageStack Project Rules

- **Solution Type:** High-Performance Focus Stacking & Computational Imaging Studio (.NET 9 WPF + Direct3D 11 ZeroGraphics GPU)
- **Architecture:** Clean Layered Architecture + Universe Plugin Standards
- **Performance Guidelines:**
  - Zero unmanaged memory leaks (use `IDisposable`, `NativeMemory`, `ArrayPool<T>`).
  - SIMD Vector256/512 for inner image computation loops + Direct3D 11 Compute Shaders for hardware acceleration.
  - End-to-end `CancellationToken` and `IProgress<T>` support across all stages.
  - Core layer must remain UI-agnostic with clean pluggable acceleration providers.
- **Dependency Portability Guidelines (`R_PKG`):**
  - All library dependencies (including `ZeroGraphics.*` and `ZeroUI.*`) must be resolved from public feeds (`nuget.org`) or relative solution artifacts.
  - Absolutely NO machine-specific absolute paths (`C:\...`, `E:\...`) in `nuget.config` or `.csproj` files to guarantee out-of-the-box clone and build across all machines and CI pipelines.
