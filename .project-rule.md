# FImageStack Project Rules

- **Solution Type:** High-Performance Focus Stacking & Image Fusion Engine (.NET 9 + C++ Native Interop)
- **Architecture:** Clean Layered Architecture + Universe Plugin Standards
- **Performance Guidelines:**
  - Zero unmanaged memory leaks (use `IDisposable`, `NativeMemory`, `ArrayPool<T>`).
  - SIMD Vector256/512 for inner image computation loops.
  - End-to-end `CancellationToken` and `IProgress<T>` support across all stages.
  - Core layer must have zero dependencies on UI.
